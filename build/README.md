# Iconos de FocusDesk

`icon.svg` reutiliza el trazado de la hoja de `src/components/Icon.tsx`, con los tonos crema y terracota de la interfaz. No contiene recursos descargados de terceros.

`icon.ico` contiene imágenes PNG de 16, 24, 32, 48, 64, 128 y 256 píxeles, generadas a partir de ese SVG. electron-builder utiliza el ICO para el ejecutable y el instalador. `public/focusdesk.png` es la versión de 256 píxeles que utiliza la ventana.

Estos archivos son recursos de marca mantenidos en el repositorio, no salidas de compilación del programa.
